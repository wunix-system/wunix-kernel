# wunix-kernel

> Монолитное ядро операционной системы Wunix для архитектуры x86_64 на языке Rust (Long Mode, протокол Limine).

## Описание

`wunix-kernel` — основное монолитное ядро операционной системы Wunix, разрабатываемое с нуля на языке Rust без использования внешнего рантайма (`#![no_std]`).

Ядро функционирует в 64-битном режиме (Long Mode) в старшей половине виртуального адресного пространства (Higher-Half, базовый виртуальный адрес `0xFFFF_8000_0000_0000`) и загружается в соответствии со спецификацией **Limine Boot Protocol v8**.

### Архитектура подсистем ядра

- **Низкоуровневая архитектура (`src/arch/x86_64/`)**:
  - Таблица глобальных дескрипторов (GDT) и сегмент состояния задачи (TSS) с изолированными стеками прерываний (IST) для защиты от двойных сбоев (Double Fault).
  - Таблица векторов прерываний (IDT) и обработчики процессорных исключений Intel.
  - Программируемый контроллер прерываний (PIC 8259A) и системный таймер (PIT 8254).
  - Ассемблерная точка входа системных вызовов через MSR-регистры (`IA32_LSTAR`, `IA32_STAR`, `IA32_FMASK`) для быстрых вызовов `syscall` / `sysret`.
- **Управление памятью (`src/memory/`)**:
  - Физический аллокатор страниц (Frame Allocator): учет свободной и занятой физической памяти блоками по 4 КиБ на основе карты памяти загрузчика.
  - Менеджер виртуальной памяти (Paging): 4-уровневые таблицы страниц x86_64 (PML4, PDPT, PD, PT), прямое отображение всей физической памяти (HHDM), изолированные адресные пространства процессов.
  - Динамическая куча ядра: потокобезопасный аллокатор `linked_list_allocator` с поддержкой контейнеров `alloc` (`Box`, `Vec`, `String`, `Arc`).
- **Процессы, потоки и планировщик (`src/task/`)**:
  - Многозадачность с вытеснением: кольцевой планировщик Round-Robin, переключающий контексты потоков по тикам системного таймера.
  - Загрузчик бинарных файлов ELF64 в изолированные адресные пространства Ring 3.
  - Модульный диспетчер системных вызовов Linux Syscall ABI, разделенный по доменам ответственности (SRP): `fs`, `mem`, `proc`, `net`, `ipc`.
- **Виртуальная файловая система (`src/fs/`)**:
  - Полиморфные абстракции трейтов `Inode` и `FileSystem` на `spin::RwLock`.
  - Корневая файловая система `ramfs` с распаковкой начального образа `initramfs.tar` (USTAR).
  - Полноценный драйвер файловой системы `FAT32` с поддержкой длинных имен файлов (LFN UTF-16) для постоянных дисковых разделов.
  - Псевдофайловые системы ядра `/proc` и `/sys`, а также аппаратные узлы `/dev` (`null`, `zero`, `tty`, `console`).
- **Драйверы оборудования (`src/drivers/`)**:
  - Видеоподсистема: линейный графический фреймбуфер Limine, растровый шрифт 8x16 (ASCII + кириллица) и эмулятор терминала VT100/ANSI.
  - Ввод-вывод: контроллер клавиатуры PS/2 с поддержкой раскладок RU/EN, переключением по Alt+Shift и комбинацией Ctrl+C; последовательный порт UART 16550 (COM1).
  - Часы реального времени CMOS (RTC MC146818).
  - Сканирование и конфигурация шины PCI.
  - Аппаратная виртуализация VirtIO: драйвер блочных накопителей `virtio-blk` и сетевой адаптер `virtio-net`.
- **Сетевой стек (`src/net/`)**:
  - Реализация стека TCP/IP поверх VirtIO-Net: уровни L2 (Ethernet, ARP), L3 (IPv4, ICMP), L4 (UDP, TCP).
  - Поддержка сокетов BSD (`socket`, `bind`, `connect`, `sendto`, `recvfrom`).
- **Интернационализация (`src/i18n/`)**:
  - Мультиязычная архитектура ядра с runtime-трансляцией диагностических сообщений на русский и английский языки.

---

## Статус реализации

- **Реализовано**: загрузка через Limine (BIOS + UEFI), GDT/TSS/IST, IDT, PIT/RTC, HHDM страничная память, аллокатор кучи, планировщик задач с вытеснением, Ring 3 переход, Linux Syscall ABI, VFS (RAMFS, FAT32 LFN, devfs, procfs, sysfs), драйверы клавиатуры, экрана, serial, VirtIO-Block и VirtIO-Net, встроенная интернационализация (RU/EN).
- **Запланировано**: многоядерность SMP (Local APIC, IO-APIC, IPI), интерпретатор ACPI AML для глубокого управления питанием, драйверы файловых систем EXT4 и Btrfs, служба активации подсистемы NT `win-init`.

## Сборка и запуск

### Требования к окружению
- Компилятор Rust (nightly toolchain) с установленной целью:
  ```bash
  rustup target add x86_64-unknown-none
  ```
- Системные утилиты: `qemu-system-x86_64`, `xorriso`, `make`, `python3`.

### Сборка ядра

```bash
# Сборка исполняемого файла ядра (ELF64)
cargo build --release --target x86_64-unknown-none
```

Скомпилированный файл ядра будет находиться по пути:
`target/x86_64-unknown-none/release/wunix-kernel`

### Запуск ядра в эмуляторе QEMU

Запуск ядра (в составе загрузочного ISO-образа с загрузчиком Limine) осуществляется стандартной командой эмулятора:

```bash
qemu-system-x86_64 \
    -boot d \
    -cdrom wunix.iso \
    -m 512M \
    -smp 2 \
    -cpu qemu64 \
    -netdev user,id=net0 \
    -device virtio-net-pci,netdev=net0 \
    -chardev stdio,id=char0,signal=off \
    -serial chardev:char0
```

Для запуска с аппаратным ускорением виртуализации KVM:
```bash
qemu-system-x86_64 -enable-kvm -cpu host -boot d -cdrom wunix.iso -m 1G -smp 2 ...
```

Для запуска в консольном headless-режиме (вывод COM1 в терминал):
```bash
qemu-system-x86_64 -display none -serial stdio -boot d -cdrom wunix.iso -m 512M
```
